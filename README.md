# 状態遷移図構築支援アプリケーション

## 概要
このWebアプリケーションは、直感的な操作で状態遷移図を作成できる教育支援ツールです。PCとスマートフォンの両方に対応しており、ドラッグ&ドロップやタッチ操作で状態遷移図を構築できます。

## 特徴
- **直感的な操作**: ドラッグ&ドロップによる状態配置と遷移線描画
- **マルチデバイス対応**: PC、タブレット、スマートフォンで動作
- **豊富な機能**: アンドゥ・リドゥ、ズーム、テンプレート、検証など
- **エクスポート機能**: PNG、SVG、PDF、状態遷移表の出力
- **URL共有**: 作成した図をURLで簡単共有

## 主な機能

### 基本機能
- **状態図形の配置**: 初期状態、通常状態、終了状態の図形を配置
- **遷移線の描画**: 状態間の遷移を矢印で表現
- **遷移条件の設定**: 遷移線上に条件やイベントを記述
- **状態の命名**: 状態図形内にテキストを直接編集
- **図形の移動**: ドラッグ&ドロップによる状態図形の自由な移動

### データ管理機能
- **JSONファイル保存・読み込み**: 作成した状態遷移図の保存と復元
- **テンプレート機能**: 目覚まし時計、自動販売機、ログインシステムなどの定型パターン
- **URL共有**: 状態遷移図データをURL化して共有

### 操作性向上機能
- **アンドゥ・リドゥ機能**: 無制限の操作履歴管理
- **グリッドスナップ機能**: 状態図形配置時の自動グリッド吸着
- **ズーム・パン機能**: マウスホイール・ピンチジェスチャーによる表示制御

### 検証・解析機能
- **状態遷移図の論理チェック**: 整合性検証と問題点の指摘
- **状態遷移表の生成**: 現在状態×イベント→次状態の表形式出力
- **到達不可能な状態の検出**: デッドステートや無限ループの検出

### エクスポート機能
- **画像形式エクスポート**: PNG/JPEG形式での高品質画像出力
- **ベクター形式エクスポート**: SVG形式での出力
- **状態遷移表エクスポート**: HTML/CSV/JSON形式での表データ出力

## 使い方

### 基本操作
1. 左パネルから状態の種類を選択（初期状態、通常状態、終了状態）
2. キャンバスをクリックして状態を配置
3. 遷移ツールを選択して状態間を接続
4. ダブルクリックで状態名や遷移条件を編集
5. ドラッグ&ドロップで状態を移動

### キーボードショートカット
- `Ctrl+S`: 保存
- `Ctrl+O`: 開く
- `Ctrl+Z`: 元に戻す
- `Ctrl+Y`: やり直し
- `Delete`: 選択項目の削除
- `T`: 遷移モード切り替え
- `V`: 検証実行
- `F`: フィット表示
- `G`: グリッド表示切り替え

### テンプレートの利用
1. 左パネルのテンプレート選択から使用したいパターンを選択
2. 「適用」ボタンをクリック
3. テンプレートが読み込まれ、編集可能な状態になります

### エクスポート機能
1. ヘッダーの「エクスポート」ボタンをクリック
2. 形式を選択（画像、ベクター、データ、共有）
3. オプションを設定して実行

## 実行方法

```bash
python -m http.server 8000
# または
npx http-server .

# ブラウザでアクセス
http://localhost:8000
```
